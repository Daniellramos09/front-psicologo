# Florável — Portal do Terapeuta Social

## Executar no VS Code
1. Extraia o ZIP.
2. Abra a pasta `floravel-single` no VS Code.
3. No terminal integrado, execute `npm install`.
4. Execute `npm run dev`.
5. Abra no navegador o endereço local mostrado pelo Vite.

O portal está concentrado em um único arquivo de interface: `src/FloravelPsychologistPortal.jsx`. Os arquivos restantes são apenas a configuração mínima necessária para o React, Vite e Tailwind.
